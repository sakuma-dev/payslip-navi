# 設計レビュー 01（公開用要約）

2026-09-28。初期設計に対して修正依頼。実装・実機の確認はこのレビューの対象外。

## 修正が必要だった点

1. 公開リポジトリには製品仕様と架空データだけを置き、画像・DB・個人バックアップ・秘密情報・個人運用記録を除外する。
2. 差引支給額と振込額、小計行、差引後の調整額を区別する。負値・還付を扱い、整合しない値を自動修正しない。
3. 復元は読み込み前のサイズ制限、全件検証、置換確認、排他トランザクション、コミット後再読込までを定義する。
4. 保存の排他性・スキーマ制約・破損検出、Android/iOSそれぞれのOSバックアップ除外を具体化する。
5. 日本語OCRの座標・言語・回転・画像縮小を統一し、表の上下行から金額を勝手に対応付けない。
6. 全角・負数・曖昧な文字・小数・支払月・元号の正規化と拒否条件を定義する。

## あわせて反映する点

デモと実DBの分離、Webの非永続プレビュー、画像と共有ファイルの清掃、個人データのログ禁止、編集時ID維持、制度説明の出典、段階ごとのレビューを受入条件にする。

契約へ反映後、差分を再レビューする。
