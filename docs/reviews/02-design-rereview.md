# 設計再レビュー 02（公開用要約）

2026-09-28。ARCHITECTURE.mdとCONTRACTS.mdの修正版を確認し、実装時の確認事項を付けて承認。設計上のブロッカーは解消した。実装と実機は別途検証する。

## 承認した修正

- 整数円・調整額・小計除外・差引支給額の定義。
- 復元前のサイズ/全件検証、排他トランザクションと失敗時ロールバック。
- SQLiteの制約・移行・破損検出、Android/iOSの保存先とバックアップ除外。
- 日本語OCRの型・座標・画像前処理と保守的な候補生成。
- 数字・月・元号の正規化、デモ分離、Web非永続、公式出典。

## 追加確認（契約へ反映済み）

- 月別項目差はカテゴリと既知コード、その他は正規化ラベルで照合し、同キーを合算する。追加/削除を区別する。
- OCRの権限拒否、未搭載、取消、空の結果を別に扱う。
- Androidの共有ファイルは受取側が遅れて読む可能性があるため即時削除せず、次回起動時に清掃する。
- OCRの括弧付き金額は負数として自動確定しない。
- ラベル長/制御文字、本人確認、警告のフィールド対応を検証する。

## 実装の受入確認

1. 公開ファイルの除外規則、secret scanning/push protection、権利表記、CIを確認する。
2. nativeのバックアップ除外が失敗したら実データ保存を開始しない。
3. 復元途中のINSERT失敗で旧データが残り、close後に新しい接続から再読込できる。
4. デモ操作が実DBを読んだり書き換えたりしない。
5. 正規化表の全ケースを架空データでテストする。
6. 日本語OCRの座標/回転/モデルを確認し、実機未確認を明記する。
7. エラーやログに明細の値・SQL・ファイルURIを含めない。
8. GUIは不一致の修正導線、算術整合の意味、バックアップによる移行、グラフの読み上げを備える。
