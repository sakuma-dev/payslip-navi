## 設計条件（§14 / 06）の充足

- **H1 巨大額の列数:** `tileColumns` がシート padding・gap・タイル padding を差し引いている。320 で 1,234,567円／-1,000,000,000円 は1列になり、数字の途中で改行しない（撮影でも確認）。
- **H2 割合帯:** 文字付き凡例あり、「帯の全体＝総支給」と明記。0円の区画・隙間・最小幅を足さない。負数・還付・調整・総支給0 では中立文言で帯を出さない。
- **H3 境界:** `lineStrong`／`inkSubtle`／`onPrimaryMuted` は §14 の値。基準線・未登録記号は `inkMuted`。
- **H4 Dialog:** Modal 内に KeyboardAvoidingView＋ScrollView がある。
- **M3 motion:**
  - 購読は `MotionProvider` 1か所で、`changed` フラグにより通知と初回問い合わせの競合を防いでいる。
  - 入場は、マウント時に `full` と確定している時だけ `useState` で固定。unknown で表示した内容を後から隠さない。
  - すべての `start()` に `stop()` のクリーンアップがある。値・棒の高さ・位置の動きはない。
- **M4:** hitSlop を廃止し、実寸44にした。**L1:** 最近の明細も `comparePayslips` の暦上の前月と比べる。**L3:** 上端色と StatusBar は §14 どおり。
- **財務の非回帰:**
  - UI 内での計算は並べ替え・比率・寸法だけ。差額の符号（当月−比較月）、データなしで他の月へ差し替えないこと、0／負数／未登録の区別、`layoutBars` と座標は維持されている。
  - domain・services・package は無変更。既存の export（`DifferenceSummary`／`SourceLinks`／`ComparisonDetail`／`Delta`／`Money`）も維持。旧画面は props 互換で型が通る。
- **独自性:** 参照のスコアリング、目標ゲージ、アイコンだけのナビは採っていない。「割合帯＋文字凡例」「中立色の控除差」「ラベル付きナビ」は給与向けの独自構成で、画像のコピーではない。

## Medium（第2段階の受入条件）

- **M1 390×844 の初期画面の密度（親所見を確認）:**
  - Web＋デモの帯（計約80px）がある時、推移は見出し・年の行・強調行までしか見えず、棒はナビの下になる。
  - 同じ値の再掲が多い: 手取り 248,550円 がステージ・凡例・推移の強調行で3回、控除 65,450円 が凡例とタイルで2回。前年同月の「データなし」がステージと比較カードで重複。推移の注記（「–」は未登録、0円は線上）は凡例と同じ内容。
  - 受入: 390×844・Web＋デモ帯ありで、推移の棒領域（144px）の上半分がナビ上端より上に見える（Playwright で棒領域の上端 y ＋ 72 ≦ ナビの上端 y）。帯なしでは棒全体が見える。
  - 手段（どれを選ぶかは実装担当）:
    - シートの値を各1回にする。例: 見出し行「総支給 314,000円（帯の全体）」＋帯＋凡例（手取り・控除）にしてタイルを外すか、凡例の金額とタイルを統合する。
    - ホームでは推移の強調行を省き、強調月は棒・月ラベルの太字だけにする。
    - 前年同月は、データがある時だけステージに出す。
    - 推移の注記は削除する（凡例に同じ内容がある）。
    - 詳細行は44pxで詰める。
  - 条件: 割合帯の文字凡例（H2）、比較月の併記、「データなし」の区別（比較カード内）は残す。E2E の `getByText('250,000円')` の `.first()`／`.last()` が意味を保つ（`.last()` は数値一覧を指す）。
- **M2 Web で増減の文脈が読まれない:**
  - `DeltaChip` は role のない `View` に `accessibilityLabel` を付けている。Web の generic div では aria-label が無視されやすい。
  - ステージでは「前月（…）比」の見える文字を `aria-hidden` にしているため、スクリーンリーダーは「+9,000円 増」だけを読み、比較先を失う。履歴の `suffix="、前月比"` も同じ。
  - 受入: 比較先を、読み上げる見える文字として残す。aria-hidden をやめ、チップ側の重複読み上げを外す。Web のアクセシビリティツリーで「+9,000円 増 前月（2026年8月）比」相当になることを確認する。
- **M3 項目差の非表示条件:**
  - `comparableItemChanges` は、どちらかの月に支給・控除の項目が1件も無いと、その区分の差を隠して「内訳が未登録」と出す。ところが控除0円で項目無しの月（未登録ではない）も「未登録」と言ってしまう。
  - 受入: 文言を事実（「どちらかの月に控除の項目が登録されていないため、控除の項目は比べていません」）に変える。片方の区分だけ隠れた時も、もう一方の区分が「変化なし」なら明示する。テストに「控除合計0・項目なし」を加える。
- **M4 確認用 spec が非公開のまま:**
  - 44px の boundingBox、横はみ出し、reduced motion の on／切替、巨大額の確認が `.local/` の spec にしかなく、CI の回帰にならない。
  - 受入: 架空データだけで、既定ポートに依存しない形にして `e2e/` へ移す（撮影は除く）。

## Low

- `StatTiles` は、ラベルの Text と金額の `accessibilityLabel`（ラベル込み）で「総支給」を2回読む。どちらか一方にする。
- ナビのラベルは `numberOfLines={1}`。320px・1.2倍で「項目ガイド」は内幅約66px の境界にある。省略記号が出ないことを 320px・文字拡大で確認する（金額ではないので Low）。
- 支給の内訳が控除0円だけの時（320-large）、凡例に「控除合計 0円」の見本色が出るが、帯に区画はない。事実どおりなので許容。見本色を枠だけにすると誤解が減る。
- native（svg／boxShadow／statusBarTranslucent／adjustResize／fontScale）は未確認。progress の申し送りどおり、compile と実機確認を第2段階の終わりまでに行う。
