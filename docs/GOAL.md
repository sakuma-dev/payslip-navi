# 実装ゴール

承認済み設計に従い、日本語iPhone/Android向け給与明細ナビを実装し、再現可能な検証と起動手順を揃える。

- [x] 日本語の端末内OCR、テキスト/手入力、確認/訂正、整数円/月/調整額/本人確認の検証と保存を実装。
- [x] 履歴・詳細・編集・削除、欠月/年またぎに対応した前月/前年同月比較、月次推移、公式出典付きガイドを実装。
- [x] SQLiteの排他書込、復元失敗時のロールバック、OSバックアップ除外、2MB/600件以内の検証付きJSON復元、独立デモ、全削除を実装・テスト。
- [x] 日本語GUIで空/読込/失敗/権限拒否/未搭載を区別し、保存結果を未確認のまま成功と表示しない。

- [x] 型・lint・73テスト・Expo依存整合・Web E2E・Android/iOS production JS exportとnative compileを確認。実機未確認は別記。
- [x] 公開ファイルを確認し、README・RESUME・検証記録を整備。最終コードをGitHubへpushしてHEADを照合。

## 段階

A: 手入力/テキスト・検証・保存・履歴CRUD。
B: 比較・推移・解説・バックアップ・デモ・GUI。
C: 日本語OCR・ネイティブ設定。
各段階でレビューと確認を行ってから統合する。

ストア配信・課金・外部OCRサーバー・アカウント同期・法定税額の自動判定はこのゴールに含めない。実機未検証を実機完成と報告しない。
