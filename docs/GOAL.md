# 実装ゴール

承認済み設計に従い、日本語iPhone/Android向け給与明細ナビを実装し、再現可能な検証と起動手順を揃える。

## 完成条件

- [ ] 日本語の端末内OCR、テキスト/手入力、確認/訂正、整数円/月/調整額/本人確認の検証を経て保存できる。
- [ ] 履歴・詳細・編集・削除、欠月/年またぎに対応した前月/前年同月比較、月次推移、公式出典付きガイドが使える。
- [ ] SQLiteの排他書込、復元失敗時のロールバック、OSバックアップ除外、2MB/600件以内の検証付きJSON復元、独立デモ、全削除が機能する。
- [ ] 日本語GUIが空/読込/失敗/権限拒否/未搭載を区別し、保存成功前に成功表示しない。
- [ ] コア・保存・OCR・GUIのレビュー記録と修正結果があり、重大指摘を解消する。
- [ ] 型・lint・テスト・Expo依存整合・Web preview・Android/iOS compileを確認し、実機未確認を区別する。
- [ ] 公開ファイルに個人データや秘密を含めず、READMEとRESUMEを実際の状態へ合わせ、push済みHEADを照合する。

## 段階

A: 手入力/テキスト・検証・保存・履歴CRUD。
B: 比較・推移・解説・バックアップ・デモ・GUI。
C: 日本語OCR・ネイティブ設定。
各段階でレビューと確認を行ってから統合する。

ストア配信・課金・外部OCRサーバー・アカウント同期・法定税額の自動判定はこのゴールに含めない。実機未検証を実機完成と報告しない。
