## §14 への対応

- **H1/M2 金額の幅:**
  - `displayStep(text, width, fontScale)` は 44/38/32/28/24 の5段。
  - `tileColumns(width, fontScale, texts, spacing)` は、シートのpadding・gap・タイルのpaddingを差し引いた内幅から、1列/2列と文字サイズを決める。
  - 符号付きの数字の途中で折り返さず、「円」の前だけで折れる。省略記号は使わない。DeltaChip と行の右側は、はみ出す時に次の行へ回り込む。
- **H2 割合帯:**
  - 帯の直下に「手取り／控除合計」の文字凡例を置き、見出しに「帯の全体＝総支給」と書いた。
  - 0円の区画・隙間・最小幅は足さない。0円、負の金額、還付、調整がある時は帯を出さず、中立の文言にする。
- **H3 境界:** 入力欄、未チェックのCheckbox、未選択のChip の枠は `lineStrong`。Segmented の選択カプセルには primary の枠を付け、太字にした。0基準線・0の印・未登録の記号は3:1以上の色。
- **H4 Dialog:** Modal の中に KeyboardAvoidingView（iOSは padding）と ScrollView を置いた。幅600未満はボトムシート、以上は中央。`placement="center"` も指定できる。
- **M3 動き:**
  - 購読は1回だけ。unknown の間に表示した内容は後から隠さない。入場の動きはマウント時に「動きあり」と確定している時だけ。
  - 押下・開閉・選択は設定の変化に追従する。すべて cleanup で stop する。金額のカウントアップ、棒の伸長、視差はない。
  - 選択カプセルは実測した位置へ置き、幅変更やRTLでも旧位置に残らない。
- **M4 押下領域:** Chip、Segmented、デモ「終了」、年送り、戻る、タブ、行は、実寸44以上を `minHeight`/`minWidth` で確保した（hitSlopには頼らない）。
- **M5:** ホームが空の時の「追加できる方法」は押せない本文の箇条書きにした。撮影・写真はOCRが無い環境で「開発ビルドで利用できます」と書く。盾アイコンは使わない。
- **M6/M7:** 推移の金額はプロットの外に置いた。年を切り替えると新しい年だけがフェードする（旧年は残らない）。
- **L1/L2:**
  - 最近の明細も `comparePayslips` の暦上の前月と比べる。
  - 比較月が無い時や差が3件以下の時は「すべての変化を見る」を出さない。
  - 詳細の比較は常に前月から開く。
  - 支給・控除の内訳が片方の月に無い場合は、項目差を「今月のみ」と見せず「比べていません」と表示する。
- **L3:** デモ帯・Web帯はスクロールの外に固定。帯が無い時のホーム（幅600未満）だけ、safe area上端を青くして StatusBar を light にする。それ以外は canvas と dark。safe area は root の padding だけで足す。
- **L4:** M11（保存完了の演出）は実装していない。

## レビュー07を受けた修正（H1・M1〜M3・Low）

変更は `src/ui/` の `components.tsx`、`TabBar.tsx`、`TrendChart.tsx`、`ComparisonView.tsx`、`screens/HomeScreen.tsx`、`visual.ts`、`visual.test.ts` だけ。他の画面ファイルは触っていない。

- **H1 ダイアログの初期フォーカス（Webのみ）:**
  - 開いた時は、Tab順に入らない見出し（`tabIndex=-1`）へフォーカスを移す。削除・同月置換・デモ破棄を開いた直後に Enter を押しても確定しない。
  - 見出しは RN Web の Modal が持つ `role="dialog"` に `aria-labelledby` で結び付けた。自前の dialog 役割は付けず、入れ子にしない。
  - 閉じたら、開いた操作へフォーカスを戻す。RN Web の Modal は閉じた直後も1回分フォーカスの囲い込みを残すため、囲い込みが外れた後の `onDismiss` で戻す。
  - native の振る舞いは変えていない。
- **M1 最初の画面の密度（390×844・Web帯＋デモ帯あり）:** 次の整理で、推移の描画領域の上端を y784 から y651 へ前倒しした（ナビ上端 y768。上端＋72 ≦ ナビ上端を満たす）。
  - 内訳シートの値を各1回にした。総支給は見出し「総支給（帯の全体） 314,000円」、手取り・控除合計は帯と同じ四角の見本を持つ数値タイルで、文字付きの凡例を兼ねる。
  - 帯を出さない明細（調整・負の金額・総支給0）では、従来どおり総支給・控除合計のタイルを出す。
  - ステージの前年同月は、データがある時だけ出す。無い時は比較カードの「前年同月」タブで「データなし」を示す。
  - 推移では、プロット外の強調行（金額の3回目の再掲）と、凡例と同じ内容の注記を削除した。表示中の月は、濃い棒・太字の月・凡例「表示中の月（濃い塗り・9月）」で示す。
  - ステージ上段を 44px にし、詳細行の上の余白を詰めた。
  - 大きな金額は従来どおり、列数と文字サイズの規則で切らずに表示する。
- **M2 増減チップの読み上げ:**
  - Webでは、チップの見える文字（「+9,000円 増」）をそのまま読ませ、aria-label に頼らない。
  - ステージの「前月（2026年8月）比」は `aria-hidden` をやめ、見える文字として読ませる。チップ側では比較先を繰り返さない。
  - 画面に比較先が書かれていない呼出（履歴の `suffix`）は、Webでは読み上げ専用の文字として足す。native は従来のラベルを使う。
- **M3 項目差を比較しない時の文言:**
  - どちらかの月に支給・控除の項目が1件もない時は、「どちらかの月に控除の項目が登録されていないため、控除の項目は比べていません。」と事実だけを書く。「未登録」とは断定しない。
  - 一方の区分だけを比べなかった時は、比べた区分の「支給の項目に変化はありません。」を明示する。
  - `comparableItemChanges` は `{ items, notCompared, unchanged }` を返す。テストに「控除合計0円・控除項目なし」を追加した。
- **Low:**
  - `StatTiles` の金額からラベルの読み上げを外した（ラベルは見える文字で1回読む）。
  - ナビのラベルは `numberOfLines` をやめ、幅が足りなければ省略記号ではなく2行に折り返す。
  - 0円で帯に区画が無い凡例の見本は、枠だけにした。
