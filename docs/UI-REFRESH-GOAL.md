## Glass版の具体的な完了条件

- 明るいScene、安定した情報面、浮遊する機能層を区別する。ナビとヘッダーのガラスは画面内で同時に1面。数値・入力・エラーを読みやすく保つ。
- iOSの対応環境ではnative素材、旧iOS/Android/Webでは対応したぼかしまたは不透明表示。初期状態不明、透明度低減、高コントラスト、強制カラー、非対応時の代替表示と購読解除を確認する。
- ガラス上の文字・選択・フォーカスを、最悪の合成背景でも識別できるようにする。影が無効になる強制カラーでもoutlineと境界が残る。
- 既存のプロジェクト構成を保ち、履歴・ガイド・設定・追加・確認編集・詳細・初回案内には、それぞれの情報と操作に合わせた配置改善を行う。
- 390×844・Web＋デモ帯ありで推移plotの上端＋72pxがナビ上端より上にある。4幅、ナビの2行ラベル、safe-areaと末尾余白、キーボードと確認ダイアログの重なりを確認する。
- 93件の単体検証と公開E2E15件を基準に、必要な設定変更・ガラス表示・確認操作の回帰を追加する。Chromium/WebKitで実画面を確認し、computedStyleだけで見た目の合格としない。
- 実装段階ごとに独立レビューを受け、重大指摘と受入条件の未解消を残さない。新コードで3platform export、Android/iOS compile、GitHub CIを通す。
- 架空データのbefore/afterと検証結果を保存し、完成した変更をmainへ共有してHEADを照合する。Notionの現在地・同じ作業履歴を更新して読み戻す。
